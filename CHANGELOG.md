# История изменений

## [1.0.0] - 2026-07-24

### Добавлено
- Сканирование штрихкодов через камеру (CameraX + ML Kit)
- Сохранение отсканированных штрихкодов в список
- Просмотр сохраненных фотографий штрихкодов
- Предпросмотр фото после сканирования с возможностью сохранения или отклонения
- Чекбоксы для выбора отдельных элементов
- Чекбокс "Выбрать все" с тремя состояниями (все/частично/ни одного)
- Кнопка удаления выбранных элементов
- Управление вспышкой/фонариком
- Зум и экспозиция
- Автоматическое определение нескольких штрихкодов в кадре
- Выбор конкретного штрихкода через FilterChip
- Поддержка горизонтальной и вертикальной ориентации
- Рамка вокруг распознанного штрихкода на камере
- Юнит-тесты для логики выбора и удаления
- Android-тесты для отображения списка и элементов

### Файлы
- `MainActivity.kt` — точка входа
- `BarcodeScannerScreen.kt` — главный экран списка
- `BarcodeItem.kt` — модель данных и enum состояний
- `BarcodeImagePreview.kt` — диалог просмотра фото
- `ManualCameraScanView.kt` — экран камеры
