# История изменений

## [1.1.0] - 2026-07-28

### Добавлено
- Отдельный экран настроек с выбором темы (светлая/темная/авто)
- Обрезка сохраненного изображения по bounding box штрихкода
- Звук затвора при съёмке
- Переход по свайпу между изображениями в превью из списка
- Отображение номера элемента в превью (N / всего)
- Открытие превью по двойному клику на элемент списка
- Поддержка перезаписи фото при повторном сканировании того же штрихкода
- Выделение чекбоксов по умолчанию

### Изменено
- Меню действий перенесено в TopAppBar: копировать/поделиться/удалить
- Пункты «Настройки» и «Выход» оставлены только в меню 3 точки
- После закрытия превью камера остаётся открытой
- Кнопка «Назад» в настройках возвращает на список, а не на камеру
- Новые штрихкоды добавляются в конец списка

## [1.0.0] - 2026-07-24

### Добавлено
- Сканирование штрихкодов через камеру (CameraX + ML Kit)
- Сохранение отсканированных штрихкодов в список
- Просмотр сохраненных фотографий штрихкодов
- Предпросмотр фото после сканирования с возможностью сохранения или отклонения
- Чекбоксы для выбора отдельных элементов
- Чекбокс "Выбрать все" с тремя состояниями (все/частично/ни одного)
- Кнопка удаления выбранных элементов
- Управление вспышкой/фонариком
- Зум и экспозиция
- Автоматическое определение нескольких штрихкодов в кадре
- Выбор конкретного штрихкода через FilterChip
- Поддержка горизонтальной и вертикальной ориентации
- Рамка вокруг распознанного штрихкода на камере
- Юнит-тесты для логики выбора и удаления
- Android-тесты для отображения списка и элементов

### Файлы
- `MainActivity.kt` — точка входа
- `BarcodeScannerScreen.kt` — главный экран списка
- `BarcodeItem.kt` — модель данных и enum состояний
- `SettingsScreen.kt` — экран настроек темы
- `FullScreenImagePreview.kt` — полноэкранный просмотр фото
- `ManualCameraScanView.kt` — экран камеры
